- Library: semble 0.5.5 (BM25 index, model loading, chunk embedding, tokenizer, RRF baseline) + model2vec `minishlab/potion-retrieval-32M` (static embeddings, brute-force cosine).
- Chunk text: breadcrumb + `context` prefix + body (+ flattened table rows). Field weights for BM25: title 3, path 2, context 1.5, body 1, citations 3, terms_defined 4.
- Fusion: BM25 top-100 + vector top-100, RRF k=60, lexical weight x2 for ID/term-like queries, then: citation short-circuit, definition resolution, title/path +0.10, hub boost log(1+refs_in)x0.02 (cap 0.10), notes -0.2, superseded filtered at as-of.
